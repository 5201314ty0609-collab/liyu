# 🐟 鲤鱼系统架构

## 概述

鲤鱼是一个自进化 AI Agent 系统，融合了 ECC、MUNDO、Metacog、Claude Soul、Superpowers、DeerFlow、TradingAgents、CowAgent、FastMCP、Graphify、claude-mem、token-savior 等 13 个项目的最佳实践。

## 核心模块

### 1. 安全层 (5层防御)

| 层级 | 功能 | 模块 |
|------|------|------|
| Layer 1 | 输入验证 | liyu-security-layer.py |
| Layer 2 | 输出净化 | liyu-security-layer.py |
| Layer 3 | 权限边界 | liyu-security-layer.py |
| Layer 4 | 审计追踪 | liyu-security-layer.py |
| Layer 5 | 注入防护 | liyu-security-layer.py |

### 2. 记忆系统

| 类型 | 功能 | 模块 |
|------|------|------|
| 渐进式披露 | 索引+按需获取 | liyu-context-compressor.py |
| 熵感知压缩 | 保留高熵内容 | liyu-context-compressor.py |
| CCR 可逆压缩 | 按需展开 | liyu-context-compressor.py |
| Deep Dream | 记忆蒸馏 | liyu-deep-dream.py |
| 会话记忆 | 跨会话持久化 | liyu-session-memory.py |

### 3. 代码图谱

| 功能 | 模块 |
|------|------|
| AST 解析 | liyu-code-graph.py |
| 知识图谱构建 | liyu-code-graph.py |
| SHA256 增量缓存 | liyu-code-graph.py |
| God Nodes 发现 | liyu-code-graph.py |

### 4. 反思循环

| 层级 | 触发条件 | 功能 |
|------|---------|------|
| Quick | ~20 signals | 调整置信度 |
| Deep | ~100 signals | 框架进化 |
| Meta | 手动触发 | 系统优化 |

### 5. 框架进化

```
Hypothesis → Observed → Validated → Hardened
```

### 6. 熔断器

```
CLOSED → OPEN → HALF_OPEN → CLOSED
```

### 7. Session Goals

- 声明式目标驱动
- 自动评估完成状态
- 安全上限（8次延续）

### 8. 辩论决策

- 多参与者轮流发言
- 辩论历史追踪
- 裁判裁决机制

### 9. 装饰器注册

- @liyu_skill — 技能装饰器
- @liyu_middleware — 中间件装饰器
- Schema 自动生成

### 10. Token 优化

- 三级优化策略 (light/medium/aggressive)
- 文件 token 分析
- 减少 80% 活跃 token
