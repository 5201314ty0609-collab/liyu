# 🐟 鲤鱼知识库

> 李(Lǐ) + 宇(Yǔ) → 鲤鱼(Lǐyú)
> 最普通的鱼，最强的适应性，跃龙门的潜力。

## 目录结构

```
00-Inbox/          → 收件箱，快速捕获想法
01-Projects/       → 项目笔记，按项目组织
02-Areas/          → 领域知识，长期维护
03-Resources/      → 参考资料，工具文档
04-Archive/        → 归档，不再活跃的内容
05-Templates/      → 笔记模板
06-Attachments/    → 附件（图片、文件）
```

## 核心理念

### PARA 方法

- **Projects**: 有明确目标和截止日期的事项
- **Areas**: 需要长期维护的责任领域
- **Resources**: 感兴趣但不需要行动的主题
- **Archive**: 不再活跃的项目/领域/资源

### 鲤鱼哲学

- **普通是起点**，不是缺陷
- **适应是能力**，不是妥协
- **成长是过程**，不是结果
- **跃龙门是可能**，不是必然
